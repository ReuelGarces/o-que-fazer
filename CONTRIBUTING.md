
# Como contribuir

Obrigado pelo interesse em contribuir com o O que fazer?!

## Antes de começar

1. Verifique se já existe uma Issue sobre o assunto.
2. Para mudanças grandes, abra uma Issue antes de implementar.
3. Crie uma branch para suas alterações.
4. Preserve a interface em português e o design existente.

## Desenvolvimento

Instale as dependências com `npm ci`.

Execute o projeto com `npm run dev`.

Antes de enviar alterações, execute:

```bash
npm run lint
npm run build
```

## Pull Requests

- Descreva as alterações realizadas.
- Explique como testou.
- Inclua capturas de tela quando alterar a interface.
- Evite incluir mudanças não relacionadas no mesmo PR.
- Nunca envie senhas, arquivos `.env` ou bancos com dados reais.

## Código de conduta

Mantenha as discussões respeitosas e construtivas.
